D 条件 · MACD 动能衰减

short_reversal 5 入场条件之一 · 仅做空策略 · 事件驱动 v3 引擎

D DIF < 0  ∧  DEA < 0  ∧  |DIF − DEA| < |prev_DIF − prev_DEA|  ·  空头反弹到顶、动能衰减
与 条件 A (close < MA60 ∧ below_ma60_ratio_60 ≥ 0.6) + B (up_streak ∈ [3,10]) + C (pct_chg ∈ [0.02, 0.07]) + E (am60 ∈ [3e7, 3e8]) 同时成立，触发做空。
close（背景） DIF DEA MACD bar (DIF−DEA) D 条件触发区 做空入场点

1DIF < 0

差离值在零线下方 — 价格处于 EMA12 之下，短期趋势仍偏弱。

MACD.macd[0] < 0

2DEA < 0

信号线也在零线下方 — 慢线也确认弱势区。

MACD.signal[0] < 0

3|bar| 缩小

bar = DIF − DEA。abs(bar[0]) < abs(bar[-1]) ⇒ 红柱高度递减 / 绿柱高度递减。

abs(DIF−DEA) < abs(prev_DIF−prev_DEA)

↑ 这是反弹末端的"动能衰减" — 多头力量耗尽，下一阶段均值回归。

数据：合成的 60 根日 K 线（下跌 → 反弹 → 见顶）。在真实 backtrader 回测中，引擎在每根 bar 的 next() 调用 _all_conditions()，仅当全部 5 条件在 T 日 close 同时成立才 入场；T+1 日 open 实际成交，避免任何穿越。 源码：short_reversal/replay_strategy_v3.py:266-276。
