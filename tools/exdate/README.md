# 除权日 (公司行动) 维度的复现脚本

日志 `docs/strategy_mining_log.md` **§10** 那一章的复现入口。
**这里不放任何结论数字** —— 数字由脚本从 DB 现场算出 (§7: 数字必须能由当前代码 + 一条命令重现)。

## 数据前提
* 事件表 `raw_adjustment_events` (57,388 条; 纯现金分红 = `dividend_per_share>0
  AND per_share_bonus=0 AND rights_ratio=0`)。
* 价格用 **`v_daily_hfq`** (后复权) —— §10.2 已验证其复权口径正确。
* ⚠️ **窗口一律截到 `2026-09-18`**: `v_daily_hfq` 在 `2026-09-21..30` 被 §13 污染
  (复权因子表落后 7 个交易日, `COALESCE(...,1)` 给出假暴跌)。
* 超额 = 该票当日收益 − **当日全市场等权**收益; 一律**逐事件日聚合** (§7.3), 不按事件池化。

## 阅读/执行顺序
| 脚本 | 回答什么 |
|---|---|
| `overlay_annualized.py` | §10.8: 聚合效应换成**年化**后够不够门槛 |
| `yield_bands.py` | §10.9: 按**股息率五档**拆 (预登记边界), 看效应是不是平的 |
| `yield_discriminate.py` | §10.9: 三个判别 —— 复权恒等式 / 价格分层 / 换自变量 (金额 vs 比率) |
| `yield_concentration.py` | §10.9: 尾部是不是少数几只票撑起来的 (票等权 + 剔大票) |
| `yield_placebo.py` | §10.9: **安慰剂 T±5** —— 是日期效应还是季节/风格效应 |
| `overlay_window.py` | §10.9: overlay 值对**回避窗口**的敏感度 (不选最优窗口) |
| `generic_reversal.py` | §10.10: **通用反转对照** —— T=0 那一跌是除权日特有, 还是"涨过就回吐" |
| `executability.py` | §10.11: overlay **可执行性** (封板/停牌) 与**容量** (§4 参与上限) |
| `host_portfolio.py` | §10.12: **宿主问题** —— 持有高股息票整年的超额 (组合级数字见 §10.13 已撤回) |
| `seasonal_check.py` | §10.13(b): 组合层季节检验的**第一版** —— ⚠️ **配对估计量加权错了, 留档作反例** |
| `seasonal_fe.py` | §10.13(c): 修正版 (暴露比例回归 + 月份固定效应) —— 结论是**组合层没有统计力** |

`python3 tools/exdate/<脚本>.py` —— 全部只读 DB, 无副作用, 无随机性。
